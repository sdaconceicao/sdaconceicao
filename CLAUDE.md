# Claude Code Instructions

Follow the repository-wide instructions in `AGENTS.md`.

Before making changes:

1. Read `AGENTS.md` — in particular the standards table and the
   "Repo-specific facts" section.
2. Read the applicable standards file in `rules/`.
3. Inspect existing implementations before introducing new patterns.

Two things here are easy to break and expensive to notice:

- **`README.md` is the GitHub profile README**, not project documentation.
- **`docs/` is stale GitHub Pages build output**, not docs. Read `DEPLOY.md`
  before touching it.
